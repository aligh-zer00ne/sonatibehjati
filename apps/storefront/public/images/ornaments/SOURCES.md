# Storefront arabesque ornaments

These six antique vector ornaments are published on Wikimedia Commons under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The source descriptions identify the original designs as antique dingbat
ornaments of unknown authorship; the SVG uploads are by Gabriel VanHelsing.

Adaptations: removed editor metadata, DTD declarations, and embedded styles;
replaced the original solid colors with a restrained gold gradient. Original
path geometry, viewBox, aspect ratio, and even-odd fill rule are preserved.
Assets are served locally and require no third-party image requests.
