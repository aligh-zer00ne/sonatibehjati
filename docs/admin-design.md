# بازبینی ظاهر و کارکرد پنل

مرجع بصری این بازطراحی، فایل HTML سامانهٔ سهامداران و تصاویر ارسالی کارفرماست. ساختار حسابداری، داده‌های نمونه، کاربران و نشان آن سامانه وارد پروژه نشده‌اند. رنگ‌های زرشکی گرم، طلایی و کرم، نشان واقعی سنتی بهجتی و فونت فعلی پروژه حفظ شده‌اند.

## رفتار مشترک

کارت‌های بخش‌ها، دریافت و پرداخت، سفارش‌ها، مشتریان، محصولات و آمار از یک الگوی بازخورد استفاده می‌کنند: حاشیهٔ زرشکی، سایهٔ نرم، هالهٔ ثابت گوشهٔ کارت و چرخش ظریف آیکون. حرکت سه‌بعدی کارت با موس حذف شده است. کارت با هاور کمی بالا می‌آید و دکمه هنگام فشردن بازخورد کوتاه دارد. لمس، پیمایش و مسیر اصلی دکمه‌ها حفظ شده‌اند؛ کارت اطلاعاتی به دکمهٔ ساختگی تبدیل نشده است.

فوکوس صفحه‌کلید مشخص است. با تنظیم Reduce motion در سیستم، چرخش/حرکت و شبکهٔ متحرک متوقف می‌شوند. پس‌زمینه‌های زرشکی جابه‌جا نمی‌شوند و شبکهٔ نقطه‌ای آن‌ها هنگام مخفی‌شدن یا خروج از دید متوقف می‌شود. منوی بالا، منوی موبایل، کنترل‌های فرم و کارت‌های مالی رفتار هماهنگ دارند.

## بخش‌های اصلی

- **داشبورد:** حلقهٔ وضعیت سفارش در یک قاب زرشکی، تعداد و سهم هر وضعیت با هاور/فوکوس، رنگ‌های خوانا و نمایش سفارش‌های همان وضعیت با کلیک یا صفحه‌کلید. شمارنده‌ها و آمار از پاسخ واقعی API هستند؛ فیلتر محل خرید، بازه‌ها و تازه‌سازی حفظ شده‌اند.
- **محصول:** فرم بخش‌بندی‌شده با مشخصات و قیمت، تصویر، تخفیف و وزن ارسال؛ توضیحات اختیاری ابتدا جمع هستند و مقدارشان حفظ می‌شود. خلاصهٔ محصول روی دسکتاپ و نوار ذخیرهٔ در دسترس اضافه شده است. پیش‌نویس، کنترل هم‌زمانی، آپلود، اعتبارسنجی، قیمت ریالی و محافظت از فاکتورهای قبلی برقرارند.
- **کاربران پنل:** فرم ساخت همکار کنار فهرست حساب‌ها و گزینه‌های دسترسی به شکل خانه‌های مشخص؛ چیدمان در موبایل زیر هم قرار می‌گیرد. اختیار انتخاب بخش‌ها و وضعیت حساب همچنان با مدیر است؛ هیچ سطح دسترسی جدید یا خودکاری اضافه نشده است.
- **مشتری و سفارش:** فرم مشتری با اطلاعات تماس و نشانی اینستاگرام منظم‌تر شده؛ کارت‌ها و دکمه‌ها بازخورد یکسان دارند. عملیات دریافت، دفتر حساب، ارسال و پرداخت بانکی تغییر نکرده‌اند.
- **پایین پنل و ورود:** عبارت «طراحی توسط nexoraict.ir» با لینک واقعی، وزن بیشتر و قاب هماهنگ مشخص‌تر شده است.
- **چاپ:** هر سه فاکتور با متن و قاب سیاه‌وسفید آماده‌اند؛ جزئیات و تنظیم چاپ در [راهنمای چاپ](printing.md) است.
- **نقشه:** فقط نمای سبک استان‌ها وجود دارد؛ SDK و کلید نشان حذف شده‌اند. [راهنمای نقشه](order-map.md).

## بررسی و انتشار

برای بررسی محلی با API/پنل ساخته‌شده و دیتابیس مهاجرت‌شده:

```bash
npm run verify:panel-review
npm run verify:dashboard-workspace
npm run verify:admin-surfaces
npm run verify:admin-login-ui
npm run verify:retail-ui
npm run verify:invoice-workspace
```

بررسی پنل ۲۹ مسیر را در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ کنترل می‌کند و ساخت/ویرایش واقعی محصول، آپلود، حفظ فیلدهای پنهان و فاکتور قبلی، ایجاد همکار و تغییر دسترسی و لمس واقعی کارت روی موبایل را بررسی می‌کند. بررسی‌های دیگر کلیک نمودار، فیلتر/صفحه‌بندی، ورود و نقش محدود، رفتار موس/لمس/کاهش حرکت، سفارش دستی/دریافت و PDF/فایل مستقل را پوشش می‌دهند. داده‌های موقت پاک می‌شوند؛ پیامک، بانک و Production واقعی مصرف نمی‌شوند. این بررسی‌ها جای آزمایش چاپگر فیزیکی فروشگاه را نمی‌گیرند.

این بازطراحی مهاجرت، کلید یا تنظیم Nginx تازه ندارد. با همان روش معمول روی سرور منتشر کنید:

```bash
git pull --ff-only origin dev && bash deploy/update-production.sh
```

فایل خصوصی محیط، تصاویر فروشگاه و داده‌های موجود را تغییر ندهید و برای این به‌روزرسانی seed/reset اجرا نکنید.
