# فاز ۲ — سیستم طراحی

مرجع قطعی: تصویر کاربر، ستون اول (صفحهٔ اصلی)، عرض هدف ۳۹۰ پیکسل.

- زمینه #FBF7EE، سطح #F4E8D3، قرمز #96140D، جوهری #2E251E. سایر توکن‌ها در globals.css (فقط توکن‌های تم shadcn).
- فونت Vazirmatn Variable محلی، جهت RTL طبیعی، اعداد با Intl فارسی، مبالغ تومان و عدد صحیح در داده.
- فاصله‌ها: ۴، ۸، ۱۲، ۱۶، ۲۰، ۲۴، ۳۲، ۴۸، ۵۶؛ شعاع کارت ۱۸–۱۹، تصویر ۱۴، Hero ۲۵، CTA گرد.
- کارت محصول: تصویر مربعی contain، علاقه‌مندی سمت چپ، نشان سمت راست، افزودن و سپس کنترل تعداد.
- شبکه محصول ۲ / ۳ / ۴ ستون در موبایل / تبلت / دسکتاپ؛ نقاط شکست ۴۸۰، ۷۶۸، ۱۰۲۴، ۱۲۸۰.
- حد محتوای دسکتاپ ۱۲۰۰ پیکسل؛ Hero دو ستونه، نوار پایین فقط موبایل و safe area.
- کنترل‌ها حداقل ۴۴ پیکسل؛ focus آشکار، لینک پرش، دیالوگ Radix با focus trap و Escape.
- primitiveهای شادکن Button، Input، Dialog، Card، Badge، Skeleton مستقل از Ant Design پنل مدیریت هستند.
- نقطه‌های Hero نشانهٔ بصری مرجع هستند؛ اسلایدر چندتصویری با دادهٔ واقعی در این فاز وجود ندارد.

استایل هر المان در className همان کامپوننت با utilityهای Tailwind تعریف می‌شود. breakpointها و variantها نیز در className و cva هستند؛ پوشهٔ `src/styles` حذف شده است.

اصلاح ظاهری پس‌زمینه: زمینهٔ کرم گرم با گرادیان ملایم و الگوی SVG تکرارشونده از کنجد، شاخه، بطری روغن، کاسهٔ ارده، حلوا، شکلات و خرما. اندازه و زاویهٔ نقش‌ها متفاوت است و رنگ کم‌رنگ خاکی با پالت برند هماهنگ می‌ماند. کارت shadcn همان نقش‌ها را بر اساس نام و دستهٔ محصول انتخاب می‌کند؛ تصویر محصول و کنترل‌ها روی لایهٔ تزئینی قرار می‌گیرند. نقش‌ها aria-hidden و pointer-events-none هستند، فایل CSS اضافه نشده و حرکت مداوم یا درخواست شبکه ندارند.

حرکت‌ها: هاور کارت با جابه‌جایی ۸ پیکسل، تقویت سایه و زوم ۸٪ تصویر؛ دکمه با بالا آمدن ۲ پیکسل، فشرده شدن هنگام لمس/کلیک و برق گذرا برای CTA. دسته‌ها و تصاویر داستان حرکت آرام دارند؛ فلش لینک‌ها و خط زیر منوی دسکتاپ هنگام هاور حرکت می‌کنند. باز/بسته شدن دیالوگ‌ها با fade/zoom/slide و حفظ محتوا تا پایان خروج است. تغییر تعداد و علاقه‌مندی بازخورد کوتاه دارد. Reveal بخش‌های پایین صفحه هنگام ورود به دید فقط یک‌بار اجرا می‌شود؛ SSR و حالت بدون JavaScript محتوای قابل مشاهده دارند و focus کیبورد نیز محتوا را آشکار می‌کند.

زمان‌ها: کنترل‌ها ۲۵۰–۳۰۰ms، کارت و دیالوگ ورود ۴۰۰ms، تصاویر و ورود بخش‌ها ۷۰۰ms و تصاویر داستان ۱۰۰۰ms؛ easing برای توقف نرم است. `prefers-reduced-motion` تمام جابه‌جایی‌ها، زوم‌ها و انیمیشن‌ها را غیرفعال می‌کند. تعاریف در classNameها هستند؛ globals.css فقط importهای Tailwind و [tw-animate-css](https://github.com/Wombosvideo/tw-animate-css) و توکن‌های تم را نگه می‌دارد، بدون CSS اختصاصی انیمیشن یا کتابخانهٔ انیمیشن JavaScript.

کامپوننت HomeSkeleton از مرز loading سراسری به components/layout منتقل شده است. صفحهٔ اصلی داده‌های سرور را پیش از نمایش محتوا دریافت می‌کند تا HTML اولیه بدون نیاز به JavaScript قابل مشاهده باشد؛ Skeleton برای حالت‌های انتظار فازهای بعد حفظ شده است.
