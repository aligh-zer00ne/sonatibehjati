# بازطراحی صفحهٔ اصلی — نسخهٔ ۴

طرح با تأیید کارفرما و بر اساس ویدیوی ارسالی ۷ اکتبر ۲۰۲۶ اجرا شده است.

- هیرو: تصویر سرتاسری، کارت روشن سمت راست در دسکتاپ و زیر تصویر در موبایل؛ تصویر، عنوان و مقصد دکمه با هم تغییر می‌کنند.
- در موبایل و تبلت از تصاویر قبلی با نسبت ۳ به ۲ برای نمایش کامل محصولات استفاده می‌شود؛ دسکتاپ از عرض ۱۰۲۴ پیکسل عکس‌های پانورامای جدید با فضای خالی سمت راست دارد. انتخاب تصویر با `picture` و `getImageProps` انجام می‌شود.
- پخش خودکار با hover، فوکوس و پنهان‌شدن تب متوقف می‌شود. انتخاب دستی پخش را متوقف می‌کند؛ دکمهٔ پخش، فلش‌های صفحه‌کلید و سوایپ موبایل در دسترس‌اند. تنظیم کاهش حرکت سیستم رعایت می‌شود.
- «داستان سنتی بهجتی» و «از دل اردکان» یک بخش هستند و بلافاصله بعد از پرفروش‌ها قرار دارند. هر دو لینک قدیمی `#story` و `#ardakan` حفظ شده‌اند.
- جای بخش داستان قبلی، پس از محصولات کنجدی، بنر فروش زرشکی با شخصیت نمونهٔ کارفرما و لینک به فروشگاه قرار دارد. عنوان و دکمه متن واقعی صفحه‌اند و داخل عکس ذخیره نشده‌اند.
- تغییرات فقط در رابط و تصاویر صفحهٔ اصلی هستند؛ تغییر schema، seed یا انتقال داده لازم نیست.

## تصاویر

تصاویر با ابزار داخلی `image_gen` و مهارت `imagegen` ساخته شدند و سپس برای وب به WebP تبدیل شدند. شخصیت بنر شفاف است؛ عکس‌های هیرو زمینهٔ واقعی و غیرشفاف دارند. تصاویر قبلی برای موبایل حفظ شده‌اند.

مسیر نهایی فایل‌ها در `apps/storefront/public/images/home/`:

- `hero-tahini-wide-v4.webp`
- `hero-oil-wide-v4.webp`
- `hero-flavored-wide-v4.webp`
- `shopping-mascot-v4.webp`

پرامپت‌ها و تصاویر ورودی در [homepage-v4-image-prompts.json](./homepage-v4-image-prompts.json) ثبت شده‌اند. معماری خطی بنر SVG داخلی کامپوننت است.

## بررسی

```bash
npm run lint
npm run typecheck
CATALOG_SOURCE=mock npm run build
npm run verify:home
```

بررسی محلی از کاتالوگ mock استفاده می‌کند. در سرور تنظیمات فعلی `CATALOG_SOURCE=api` و فایل‌های خصوصی محیط حفظ شوند تا محصولات واقعی همان دیتابیس نمایش داده شوند.
