# اصلاح هیرو و داستان در موبایل و تبلت

این نسخه چیدمان توضیح‌داده‌شده در `homepage-v4.md` را اصلاح می‌کند: کادر متن هیرو در تمام اندازه‌ها روی تصویر، در سمت راست باقی می‌ماند و متن داستان نیز همیشه کنار عکس اردکان قرار دارد. تیتر، فاصله‌ها و متن موبایل کوتاه‌تر و کوچک‌تر شده‌اند؛ دکمه‌ها همچنان حداقل ۴۴ پیکسل ارتفاع دارند. زمینهٔ کادر هیرو و داستان گرادیان گرم عسلی و مسی است. استایل‌ها در `className` و دکمه‌ها با کامپوننت shadcn موجود پیاده شده‌اند.

## تصاویر تازه

سه صحنهٔ تازه با ابزار داخلی image_gen و بر پایهٔ عکس‌های واقعی مجموعه ساخته شده‌اند:

- اردهٔ در حال ریختن و بسته‌بندی‌های گروهی، با میز چوبی و ترمه.
- چهار بسته‌بندی روغن کنجد، با گلیم و ظروف مسی.
- ارده شکلاتی بازشده، کرم ارده و ارده فندقی، با میز منبت و ظروف سنتی.

هر صحنه دو قاب مستقل دارد: عریض برای عرض ۷۶۸ پیکسل به بالا و عمودی برای موبایل. عکس‌های قدیمی دست‌نخورده باقی مانده‌اند، اما هیرو دیگر از آن‌ها استفاده نمی‌کند. نسخهٔ جدید هیچ تغییری در تصاویر محصول، داده‌ها یا تنظیمات سرور ایجاد نمی‌کند.

فایل‌های نهایی در `apps/storefront/public/images/home/hero-*-v5.webp` ذخیره شده‌اند. ابعاد واقعی خروجی مدل برای تصاویر عریض ۱۹۴۲×۸۰۹ و برای موبایل ۱۱۲۲×۱۴۰۲ پیکسل است. تبدیل به WebP با کیفیت ۹۴، بدون کوچک‌کردن یا بزرگ‌نمایی مصنوعی انجام شده است؛ Next.js اندازهٔ مناسب دستگاه را با کیفیت ۸۵ ارائه می‌کند. عکس‌ها حاصل بازطراحی مولد بر پایهٔ مرجع‌اند و چاپ برچسب‌ها باید در بازبینی نهایی برند هم بررسی شود.

عکس‌های مرجع، متن کامل درخواست تولید و مسیر فایل‌ها در `homepage-v5-image-prompts.json` ثبت شده‌اند.

## بررسی

`npm run lint`، `npm run typecheck`، `CATALOG_SOURCE=mock npm run build` و `npm run verify:home` با موفقیت اجرا شدند. بررسی مرورگر عرض‌های ۳۲۰، ۳۷۵، ۴۸۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل را پوشش می‌دهد: متن روی تصویر، داستان دو ستونه، نبود هم‌پوشانی کنترل‌ها و دکمه، گرادیان‌ها، انتخاب تصویر مناسب و نبود اسکرول افقی. رفتار اسلایدر، سبد خرید، جستجو، دسته‌بندی، کاهش حرکت و نمایش بدون JavaScript نیز بررسی شد.

برای مشاهدهٔ محلی با داده‌های نمونه:

```sh
CATALOG_SOURCE=mock npm run dev:storefront
```

این اصلاحات تا اجرای روند به‌روزرسانی سرور، صرفاً در نسخهٔ پروژه اعمال شده‌اند.
