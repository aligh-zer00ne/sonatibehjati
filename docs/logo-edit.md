# ویرایش لوگوی سنتی بهجتی

ابزار: built-in image_gen.imagegen؛ حالت precise-object-edit.
ورودی: `apps/storefront/public/images/logo.webp`، برگرفته از PDF رسمی کاربر.
خروجی استفاده‌شده در سایت: `apps/storefront/public/images/logo-brand.png`.

دستور نهایی ویرایش:
حذف فقط حروف سفید «روغن (ارده) کنجد ممتاز» از روبان طلایی پایین و بازسازی سطح طلایی زیر حروف. خود روبان و پیچ‌وتاب آن حفظ شوند. خوشنویسی مرکزی «سنتی بهجتی»، سپر قرمز، حاشیهٔ طلایی، نقش گل بالایی، برگ‌های سبز، نشان کوچک سبز و سفید و نوشته‌های آن، سایه‌ها، تناسبات و زمینهٔ سفید حفظ شوند. هیچ نوشتهٔ جدید یا بازطراحی اضافه نشود.

متن حذف‌شده و ظاهر کلی خروجی بصری بررسی شده‌اند. فایل اصلی PDF برای مرجع باقی مانده است.

## لوگوی برداری فوتر

فایل `apps/storefront/public/images/logo-footer.svg` از مسیرهای برداری PDF اصلی
`logo-original.pdf` استخراج شده است: سپر، نقش بالایی، خوشنویسی «سنتی بهجتی» و روبان طلایی.
زمینهٔ سفید صفحه، سایه‌های پیکسلی، وصلهٔ تصویری برگ‌ها و نشان کوچک داخل آن، و نوشتهٔ
حذف‌شدهٔ «روغن (ارده) کنجد ممتاز» وارد نسخهٔ برداری فوتر نشده‌اند. این نسخه هیچ تصویر
پیکسلی جاسازی‌شده، فونت وابسته یا منبع خارجی ندارد؛ زمینه شفاف است و شکل حروف از PDF اصلی
حفظ شده است. viewBox به محدودهٔ نشان محدود و دقت مختصات و تعداد ایستگاه‌های گرادیانت
برای نمایش در وب بهینه شده‌اند. فایل PNG فعلی همچنان برای سایر محل‌های سایت حفظ شده است.
