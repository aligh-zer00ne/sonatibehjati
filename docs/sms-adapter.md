# آداپتور پیامک ملی‌پیامک

منبع پیاده‌سازی نمونهٔ `SmsService.ts` ارائه‌شده توسط کاربر از مسیر `/home/zer00ne/Downloads/Telegram Desktop/SmsService.ts` است. فایل اصلی شامل NestJS بود؛ آداپتور Express پروژه در `apps/api/src/services/meliPayamakSms.ts` همان قرارداد قالب پیامک را پشت interface مستقل `SMSService.sendOTP` اجرا می‌کند.

درخواست HTTPS به `console.melipayamak.com:443/api/send/shared/{apiKey}` با بدنهٔ `{ to, bodyId, args: [code] }` می‌رود. کلید، مسیر و شناسهٔ الگو در constructor تنظیم می‌شوند. timeout ده ثانیه، رد redirect، بررسی `recId` مثبت و خطای عمومی بدون افشای پاسخ/کلید حفظ شده‌اند. تست‌ها fetch کنترل‌شده دارند و پیامک واقعی ارسال نمی‌کنند. کلید کنسول فقط در فایل خصوصی ذخیره شده است؛ شناسهٔ عددی الگوی واقعی هنوز ارائه نشده و ارسال زنده تأیید نشده است.

کد ورود پنج‌رقمی است و با مولد تصادفی رمزنگاری در API ساخته می‌شود؛ صفر ابتدایی حفظ می‌شود. محدودیت پنج تلاش، اعتبار سه دقیقه و فاصلهٔ ارسال مجدد یک دقیقه برقرارند. متن در الگوی تأییدشدهٔ ملی‌پیامک تنظیم می‌شود: «کد ورود شما به سنتی بهجتی: {0}». عنوان یا متن پیام جایگزین `bodyId` عددی نیست.

## بررسی نمونهٔ REST تحویلی

فایل `Rest-Sample.zip` شامل چهار گروه نمونه است: `SendSMS`، `BaseServiceNumber`، `GetDeliveries` و `GetMessages`. کدهای آن از سال‌های ۲۰۱۷ و ۲۰۱۹ هستند. فایل `BaseServiceNumber/HTTP-Sample.txt` ارسال پترن را با فرم URL-encoded به `rest.payamak-panel.com/api/SendSMS/BaseServiceNumber` و پارامترهای `username`، `password`، `to`، `text` و `bodyId` نشان می‌دهد. مقدار `bodyId=123` و مقادیر `YourUserName` و `YourPassword` صرفاً نمونه‌اند. مسیر ارسال عادی `SendSMS` شمارهٔ فرستنده نیز می‌خواهد و جایگزین مستقیم ارسال پترن نیست.

[مستند رسمی ملی‌پیامک](https://www.melipayamak.com/api/) سرویس کنسول مبتنی بر Auth Token را جدا معرفی می‌کند. [مستند ارسال پترن](https://www.melipayamak.com/api/sendbybasenumber/) نیز کد الگوی تأییدشده را لازم می‌داند و خطای الزام استفاده از API key به‌جای رمز عبور را توضیح می‌دهد. کاربر مشخص کرده کلید از **کنسول ملی‌پیامک** صادر شده؛ بنابراین آداپتور فعلی کنسول حفظ می‌شود و برای اتصال آن نام کاربری REST لازم نیست. نمونهٔ REST شناسهٔ واقعی الگوی کاربر را در اختیار نمی‌گذارد.

استفاده در احراز هویت و متغیرهای محیطی در `docs/phase5.md` توضیح داده می‌شوند.
