# آداپتور پیامک ملی‌پیامک

آداپتور Express پروژه در `apps/api/src/services/meliPayamakSms.ts` قراردادهای SOAP پترن و کنسول را پشتیبانی می‌کند. کلید فقط در فایل خصوصی `apps/api/.env` با نام `MELI_PAYAMAK_API_KEY` نگهداری می‌شود؛ قسمت انتهایی URL نمونهٔ اختصاصی کنسول همان کلید است و نباید وارد Git شود.

- **SOAP پترن، انتخاب فعلی مالک:** `MELI_PAYAMAK_TRANSPORT=soap` و نام کاربری/رمز وب‌سرویس پنل در `MELI_PAYAMAK_USERNAME` و `MELI_PAYAMAK_PASSWORD`. آداپتور `meliPayamakSoap.ts` متد `SendByBaseNumber` را با `text: [code]`، `to` معتبر و الگوی `559650` به `https://api.payamak-panel.com/post/send.asmx` می‌فرستد. namespace و SOAPAction از [WSDL رسمی](https://api.payamak-panel.com/post/send.asmx?wsdl) بررسی شده‌اند. کد در سایت تولید و فقط هش آن ذخیره می‌شود. این جریان از سرویس OTP کنسول استفاده نمی‌کند. نسخهٔ npm بستهٔ نمونه (`melipayamak-api@0.1.0`) متد مذکور را ندارد و یک خطای نحوی در ماژول SOAP دارد؛ خود قرارداد SOAP با fetch HTTPS و parser XML پیاده شده است. XML و Soap Fault/exception خام، رمز، شماره و کد هرگز log نمی‌شوند. DTD/ENTITY و پاسخ مبهم/خراب/بیش از 64KiB رد می‌شوند؛ نتیجهٔ مثبت به‌صورت رشتهٔ BigInt بررسی می‌شود تا شناسهٔ بزرگ دقت خود را از دست ندهد. ارسال تکراری یا fallback خودکار وجود ندارد.
- **OTP کنسول، مطابق نمونهٔ جدید مالک:** مسیر `MELI_PAYAMAK_PATH=/api/send/otp/{apiKey}`، بدنهٔ JSON فقط `{ to }`، پاسخ `{ code, status }`. شماره از ورودی معتبر مشتری می‌آید. OTP باید در کنسول فعال و طول آن ۵ تنظیم شود. متن و خط در کنسول تنظیم می‌شوند؛ `bodyId` و `args` به این مسیر ارسال نمی‌شوند. کد برگشتیِ پنج‌رقمی رشته‌ای، با حفظ صفر ابتدایی، به احراز هویت برمی‌گردد و همراه `sentAt` فقط هش آن ذخیره می‌شود. کد محلیِ جایگزین‌شده معتبر نیست و کد واقعی هیچ‌وقت به مرورگر برگردانده نمی‌شود.
- **قالب shared:** مسیر `/api/send/shared/{apiKey}`، بدنهٔ `{ to, bodyId, args: [code] }` و پذیرش فقط با `recId` مثبت. برای قالب تأییدشدهٔ `559650` این روش استفاده می‌شود؛ کد در API ساخته می‌شود. این روش از نمونهٔ قبلی `SmsService.ts` مالک اقتباس شده بود و برای استفادهٔ صریح از همان قالب حفظ شده است.

ابزار انتشار با `--sms-mode=soap --body-id=559650` روش فعلی را انتخاب می‌کند؛ گزینه‌های قبلی `otp` و `shared` برای انتخاب صریح حفظ شده‌اند و `MELI_PAYAMAK_TRANSPORT=console` را تنظیم می‌کنند. در اجرای دوباره بدون گزینه، روش تنظیم‌شده را حفظ می‌کند. SOAP و shared به bodyId عددی نیاز دارند؛ در OTP، نبودن bodyId مجاز است. نمونهٔ جدید OTP به‌تنهایی تأیید نمی‌کند کلید روی سرور معتبر است؛ کلید تازهٔ همان کنسول باید در env سرور ذخیره شود.

timeout ده ثانیه، رد redirect، محدودیت ارسال مجدد یک دقیقه، اعتبار سه دقیقه، سقف پنج تلاش، انقضا و مصرف یک‌باره حفظ می‌شوند. کد OTP با طول نامعتبر رد می‌شود؛ fallback یا ارسال تکراری خودکار وجود ندارد. خطای عمومی سایت جزئیات سرویس را افشا نمی‌کند؛ log سرور فقط دلیل پالایش‌شده را دارد. تست‌ها fetch کنترل‌شده دارند و پیامک واقعی ارسال نمی‌کنند. کد عمومی [کنسول OTP](https://console.melipayamak.com/send/otp) و [کنسول shared](https://console.melipayamak.com/send/shared) به‌همراه نمونهٔ مالک برای تطبیق قرارداد بررسی شدند؛ دریافت واقعی روی سرور هنوز تأیید نشده است.

## بررسی نمونهٔ REST تحویلی

فایل `Rest-Sample.zip` شامل چهار گروه نمونه است: `SendSMS`، `BaseServiceNumber`، `GetDeliveries` و `GetMessages`. کدهای آن از سال‌های ۲۰۱۷ و ۲۰۱۹ هستند. فایل `BaseServiceNumber/HTTP-Sample.txt` ارسال پترن را با فرم URL-encoded به `rest.payamak-panel.com/api/SendSMS/BaseServiceNumber` و پارامترهای `username`، `password`، `to`، `text` و `bodyId` نشان می‌دهد. مقدار `bodyId=123` و مقادیر `YourUserName` و `YourPassword` صرفاً نمونه‌اند. مسیر ارسال عادی `SendSMS` شمارهٔ فرستنده نیز می‌خواهد و جایگزین مستقیم ارسال پترن نیست.

[مستند رسمی ملی‌پیامک](https://www.melipayamak.com/api/) سرویس کنسول مبتنی بر Auth Token را جدا معرفی می‌کند. [مستند ارسال پترن](https://www.melipayamak.com/api/sendbybasenumber/) نیز کد الگوی تأییدشده را لازم می‌داند و خطای الزام استفاده از API key به‌جای رمز عبور را توضیح می‌دهد. کاربر مشخص کرده کلید قبلی از **کنسول ملی‌پیامک** صادر شده بود؛ در آخرین درخواست، کاربر روش SOAP با نام کاربری و رمز وب‌سرویس پنل را انتخاب کرده است. نمونهٔ REST شناسهٔ واقعی الگوی کاربر را در اختیار نمی‌گذارد.

استفاده در احراز هویت و متغیرهای محیطی در `docs/phase5.md` توضیح داده می‌شوند.
