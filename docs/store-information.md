# اطلاعات فروشگاه

از «مدیریت ← اطلاعات فروشگاه» نام فروشگاه، شماره تماس، نشانی کامل و کد پستی ده‌رقمی را ثبت کنید. پیش‌نمایش سمت صفحه، قسمت فرستندهٔ لیبل را نشان می‌دهد؛ تغییرات پس از «ذخیره اطلاعات فروشگاه» اعمال می‌شوند. شماره و کد پستی با ارقام فارسی/عربی نیز پذیرفته و برای نگهداری یکسان می‌شوند.

پس از اولین ذخیرهٔ کامل، تمام لیبل‌هایی که باز می‌کنید مشخصات فرستنده را از این تنظیم می‌خوانند؛ مشخصات قدیمی فرستنده در لیبل یک سفارش بر آن مقدم نیست. مشخصات گیرنده، کالاها، وزن، هزینه و مبالغ همچنان از سفارش می‌آیند و تغییری در سفارش یا فایل‌های چاپ‌شدهٔ قبلی ایجاد نمی‌شود. تا پیش از تکمیل تنظیمات، مشخصات فرستندهٔ قدیمی همان سفارش یا اطلاعات عمومی فعلی فروشگاه حفظ می‌شود؛ کد پستی فرضی ساخته نمی‌شود. تنظیمات عمومی صفحات سایت و SEO در این تغییر دست‌کاری نمی‌شوند.

مدیر کامل دسترسی دارد. برای همکار، دسترسی مستقل «اطلاعات فروشگاه» را در «مدیریت ← کاربران پنل» بدهید. همکار دارای دسترسی سفارش‌ها همچنان می‌تواند لیبل با مشخصات فروشگاه چاپ کند، بدون اجازهٔ تغییر این تنظیم. داده از API معتبر می‌آید و فقط در حافظهٔ مرورگر نگهداری نمی‌شود.

اگر دو مدیر هم‌زمان ویرایش کنند، ذخیرهٔ قدیمی با پیام تعارض رد می‌شود و متن فرم از بین نمی‌رود. «دریافت اطلاعات جدید» پس از تأیید کنارگذاشتن ویرایش‌های ذخیره‌نشده، نسخهٔ تازه را بارگیری می‌کند.

## انتشار و بررسی

مهاجرت افزایشی `202610230004_store_information` فقط جدول این تنظیم را اضافه می‌کند؛ داده‌های موجود، تصاویر، سفارش‌ها و فایل‌های خصوصی تغییر نمی‌کنند. از مسیر پروژه روی سرور، به روش معمول اجرا کنید:

```bash
git pull --ff-only origin dev && bash deploy/update-production.sh
```

اسکریپت، Prisma و مهاجرت را مدیریت می‌کند؛ تنظیم جدید محیط یا Nginx لازم نیست. پس از انتشار، چهار مقدار واقعی را ذخیره کنید، صفحه را دوباره باز کنید و از یک سفارش لیبل بگیرید تا مشخصات فرستنده کنترل شود. فایل PDF قبلاً دانلودشده خودکار تغییر نمی‌کند.

برای بازآزمایی محلی با دیتابیس مهاجرت‌شده و API/پنل ساخته‌شده:

```bash
npm run verify:store-information
npm run verify:invoice-workspace
```

بررسی اول تنظیمات قبلی را دقیقاً برمی‌گرداند و داده/حساب‌های موقت را پاک می‌کند؛ اعتبارسنجی، اولین ذخیرهٔ هم‌زمان، دسترسی و Origin، ماندگاری، تعارض، پیش‌نمایش موبایل و استفاده در لیبل را کنترل می‌کند. بررسی دوم قالب‌های واقعی PDF فاکتور و لیبل را کنترل می‌کند؛ هیچ پیامک یا درخواست بانکی واقعی ارسال نمی‌شود.
