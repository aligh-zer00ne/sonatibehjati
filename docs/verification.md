# نتیجهٔ بررسی فازهای ۱ تا ۳

- lint: بدون خطا، با npm و Bun.
- typecheck: همهٔ workspaceها موفق، با npm و Bun.
- build: فروشگاه Next.js، پنل Vite و API TypeScript موفق.
- تست واحد: ۵ تست؛ هزینهٔ ارسال و محدودیت عمق/پیچیدگی GraphQL، از جمله بسط تکراری fragment.
- Migration: اعمال روی MySQL 8.4 موقت، schema معتبر.
- Seed: اجرای دوباره بدون تکرار دسته‌ها و سفارش نمونه.
- API: خواندن محصولات از MySQL، CORS، serialization قیمت/تاریخ، محصول ناموجود و جلوگیری DB از حذف محصول استفاده‌شده در سفارش.
- مرورگر Chrome: عرض ۳۹۰ و ۱۴۴۰؛ RTL، بدون overflow افقی، نوار پایین فقط موبایل، افزودن و تغییر تعداد، حفظ سبد بعد از reload، جمع سبد، جستجوی بی‌نتیجه و موفق، انتخاب دسته‌بندی، منو و Escape؛ بدون pageerror.
- تصاویر محصولات و معماری نمونه، برش مرجع کاربر با وضوح محدود هستند؛ اطلاعات تجاری واقعی هنوز دریافت نشده است.
- اخطار غیرمسدودکنندهٔ Vite: باندل اولیهٔ Ant Design پنل بیش از ۵۰۰ کیلوبایت است. تقسیم کد صفحات مدیریتی در فاز ۸ تکمیل می‌شود.

اسکریپت‌ها: `npm run verify:home` پس از build و با Chrome محلی؛ `npm run verify:api` با DATABASE_URL دیتابیس آزمایشی seeded. این اسکریپت API محدودیت حذف محصول سفارش نمونه را با تلاش حذف و انتظار خطای FK بررسی می‌کند؛ آن را فقط روی دیتابیس توسعه/تست اجرا کنید.

اصلاحات UI و نام برند: پوشهٔ CSS جدا حذف و استایل‌ها به classNameهای Tailwind و primitiveهای shadcn منتقل شدند. lint، typecheck، build هر سه برنامه، ۵ تست واحد، format:check و بررسی مرورگر موبایل/دسکتاپ دوباره موفق شدند. اسکرین‌شات‌ها پس از decode همهٔ تصاویر ثبت می‌شوند. حذف متن روبان لوگو و استفاده از «سنتی بهجتی» در متن‌های سایت بررسی شد.

پس‌زمینهٔ وکتوری و کارت‌های متناسب با محصول: lint، typecheck، build هر سه برنامه و بررسی مرورگر ۳۹۰/۱۴۴۰ موفق شدند؛ بدون خطای اجرا یا overflow افقی و با حفظ عملکرد سبد، جستجو، دسته‌بندی و منو. نقش‌های SVG در موبایل و دسکتاپ بصری بررسی شدند؛ لایه‌های تزئینی کلیک‌ها را نمی‌گیرند و در درخت دسترس‌پذیری حضور ندارند.
